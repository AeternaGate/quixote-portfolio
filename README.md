# Quixote.Dev — Portfolio

Portfolio site for **Quixote.Dev**, built with React and a dash of WebGL flair.

## ✨ Features

- Modern, responsive single-page layout
- Scroll-driven animations with GSAP / ScrollTrigger
- WebGL effects (React Three Fiber) and liquid-ether visuals
- Lightweight routing between story and projects
- i18n-ready (EN / RU)

## 🛠 Tech Stack

| Technology | Purpose |
|------------|---------|
| [React 18](https://react.dev) | UI library |
| [TypeScript](https://www.typescriptlang.org) | Typed JavaScript |
| [Vite](https://vitejs.dev) | Build tooling |
| [Tailwind CSS](https://tailwindcss.com) | Styling |
| [GSAP / ScrollTrigger](https://gsap.com) | Animation |
| [React Three Fiber](https://r3f.docs.pmnd.rs) | WebGL / 3D |

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Production build
npm run build

# Preview the production build
npm run preview
```

## 📁 Structure

```
src/
├── components/   # UI components (Hero, Work, About, Nav, ...)
├── pages/        # Route-level pages
├── styles/       # Global styles
├── i18n.ts       # Translations
└── App.tsx       # App entry
```
